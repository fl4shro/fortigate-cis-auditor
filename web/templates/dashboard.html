Recomendação para uma análise mais precisa
Geração da configuração completa pelo CLI do FortiGate

Para obter a melhor cobertura durante a avaliação, recomendamos gerar o arquivo de configuração diretamente pelo CLI do FortiGate.

No FortiGate, execute os comandos abaixo:

FORTIGATE CLI
config system console set output standard end show full-configuration

Após executar o comando, salve toda a saída apresentada pelo CLI em um arquivo com extensão .conf e envie o arquivo nesta página.

Importante: não interrompa, filtre ou omita partes da saída. A configuração completa permite que o auditor avalie corretamente os controles aplicáveis do CIS Benchmark.
🔒 Privacidade: seu arquivo .conf é processado somente em memória para executar a análise. O arquivo de configuração não é armazenado permanentemente no servidor. O resultado fica disponível apenas nesta sessão do navegador e expira automaticamente.
